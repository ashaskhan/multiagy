# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Multiagy (especially regarding credential isolation or archive extraction safety), please report it responsibly:

1. **Do not** open a public issue.
2. Email the maintainer directly at `ashaskhan001@gmail.com` or use GitHub's private vulnerability reporting feature.
3. Include details of the vulnerability and steps to reproduce.

We will review, patch, and release an update as promptly as possible.
